# 昆蟲探險家

認識台灣昆蟲的 K-12 教學網站：<https://insects.hunglun.com>

給老師課堂使用，免註冊、免安裝。題目分國小、國中、高中三級難度。

工具：昆蟲小百科、搜尋（昆蟲＋標本）、猜猜我是誰、分類闖關、是不是昆蟲、翻牌配對、變態排排站、幾月看得到、標本館探究、我的小圖鑑、探險護照、老師專區（學習單、投影出題、搶答計分板、課程包）。

## 資料來源與授權

- 農業部林業試驗所昆蟲標本館資料（約 14.8 萬筆標本），來源為[政府資料開放平臺](https://data.gov.tw/dataset/7278)，依政府資料開放授權條款第 1 版使用。
- 物種中文名、別名、特有種、外來種、保育等級、臺灣紅皮書等級：[臺灣物種名錄 TaiCOL](https://taicol.tw/)（CC BY 4.0）。
- 照片與每月觀察筆數：[iNaturalist](https://www.inaturalist.org/) 台灣「研究級」觀察。只使用 CC0、CC BY、CC BY-SA 授權的照片，網站上每張照片都標示作者與授權；本站將照片縮小後自行存放。
- 範本白話句只把上述資料欄位接成句子，不另外編寫內容。常見昆蟲的白話介紹（`data/ai_plain.json`）由 AI 依維基百科摘要改寫並查核，網站上標示「AI 改寫」與依據的條目（CC BY-SA 4.0）。
- 本站不是上述機關或網站製作。

## 架構

一支 Cloudflare Worker 提供網頁（`public/`）、API（`src/api.ts`）、照片（`src/img.ts`，R2）與每月檢查（`src/check.ts`）。資料存在 D1，標本搜尋用 FTS5（中文自己切成單字＋兩字一組，見 `tools/tokens.py`、`src/tokens.ts`）。物種約一千多種，整份一次給瀏覽器，遊戲在瀏覽器裡出題。

資料整理在本機跑（`tools/`）：下載 → 整理（中文名、目、縣市、出題池）→ 產生 SQL 匯入 D1；照片下載 → 轉 webp → 上傳 R2。

## 開發

```
npm install
pip install zhconv
npm test                         # 離線測試：目名、學名、縣市、簡體字、照片挑選、搜尋切詞
npx wrangler dev                 # 本機啟動
```
